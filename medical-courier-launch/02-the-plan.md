## Phase 2 — Stand up your own insured "prime" line

**Trigger (don't start before this):** you have **one signed/verbal recurring route** (e.g., an LTC pharmacy daily run) that anchors the fixed costs.

### Compliance setup checklist (operator-runnable)

- [ ] Written **OSHA Exposure Control Plan** (free OSHA template) — review annually
- [ ] **HIPAA**: BAA template ready; annual driver training; PHI-handling SOP (sealed opaque bags, locked-in-vehicle)
- [ ] **DOT UN3373**: triple-packaging supplies on hand; hazmat training (renew every 3 yrs); dry-ice (UN1845) handling if frozen
- [ ] **Chain of custody**: PoD app + manifest (formal CCF only needed for drug-testing/forensic specimens)
- [ ] **PA PUC intrastate Property authority** ($100; have insurer file Form E + Form H)
- [ ] **Philadelphia Commercial Activity License** (free) + BIRT if running into the city; **Upper Darby Business Privilege License** (~$50/yr)
- [ ] Verify **PA DEP waste permit NOT needed** (specimens-to-lab ≠ waste) — call PA DEP to confirm before any waste runs

**Reality:** ~**$5–7k/yr** for one vehicle, **$12–20k+** for two/refrigerated. Most is paid monthly, so binding cash is a few hundred dollars — but the *recurring* number is why you need an anchor route first.

### Driver training list (one-time + annual)

1. OSHA Bloodborne Pathogens (annual, $15–40) · 2. HIPAA (annual) · 3. DOT UN3373 hazmat (every 3 yrs, ~$30–40) · 4. Dry-ice handling (if frozen) · 5. Your chain-of-custody + PoD SOP (in-house, free).

### Proof-of-delivery + temperature-log system (cheapest that actually works)

- **PoD:** barcode/label scan + digital signature + timestamp + GPS at pickup AND delivery. Cheapest path: the **prime's app** (Phase 1); for your own routes, a low-cost route/PoD app. [V]
- **Temp logs:** reusable insulated cooler (**$20–150**) + single-use or reusable **USB temp logger ($15–40)** that exports a PDF per run. For short intra-city runs, a documented "hold-time study" (cooler + logger + timed test run) satisfies most labs cheaply. [V]
- **Validated pharma-grade cooler** (e.g., ~$929 PCM unit) only if a client demands it. [V]
